# AI Novelist Studio

AIのべりすと（`spiko_ultra` 固定）と会話しながら小説を生成・執筆・管理していく、個人開発のAI執筆スタジオです。

会話の中で `#タグ` を使ってカード（世界観・キャラ設定・伏線など）を呼び出したり、リッチテキストのドキュメントや原稿ペインに本文を蓄積したり、複数の会話・資料・作品データをプロジェクト単位で管理できます。PCはもちろん、スマホやChromeOSのブラウザからも使えます。

## クイックスタート

1. [Releases](https://github.com/WLeln/ai-novelist-studio/releases) から `AI Novelist Studio Setup x.x.x.exe` をダウンロード・インストール
2. アプリを起動し、設定画面で**AIのべりすとのAPIキー**を登録
3. チャットで「こんにちは」と話しかける → あとは会話しながら執筆

詳しい使い方は **[MANUAL.md](MANUAL.md)**（ユーザーマニュアル）を参照してください。

## 特徴

| カテゴリ | 主な機能 |
|---|---|
| **創作** | AIチャット、原稿ペイン（章・シーン構成）、リッチテキストドキュメント、章単位AI執筆、ゴースト補完、流れ生成 |
| **設定管理** | カードDB（別名・関連・伏線トラッカー）、ノート（Zettelkasten）、ソースQ&A、物語グラフ |
| **品質** | 一貫性チェック、ローカル校正（MeCab/UniDic・AI不要）、表現チェック、文体分析 |
| **記憶・効率** | ハイブリッド記憶、コンテキスト自動圧縮、繰り返しワード検出、プロンプト最適化、クイックマクロ |
| **管理** | タイムマシン、バックアップ/復元、シーン履歴、横断検索・置換、エクスポート |

### 創作ワークフロー
- **会話しながら生成** — AIとのチャットがそのまま創作の現場
- **原稿ペイン** — AIの応答をワンタップで原稿に採用。章・シーン構成で整理して執筆。章単位のAI一括執筆にも対応
- **リッチテキストドキュメント** — TipTapベースのエディタ。ルビ・傍点・リンクなどの書式に対応
- **カスタムリライトタグ** — ドキュメント内で `AZ[対象テキスト]` のような2文字タグを登録・実行。連続タグ・グループ統合・`,数字`での文字数指定に対応。さらに組み込みの `AAA[対象,指示,字数]`（対象への指示適用）と `BBB[指示,字数]`（指示からの生成）も使えます
- **流れメモ** — ドキュメント右側に順序付きメモパネルを表示。プロットの流れを `↓` 付きでメモできます
- **執筆統計** — 総文字数・目標達成率・本日の執筆ペースをリアルタイム表示
- **次の一手提案** — 応答完了ごとに次の指示候補を3つ提示（ワンタップ送信・設定でOFF可）
- **伏線トラッカー** — 伏線カードの未回収/回収済を管理し、AIが「このシーンで回収すべき伏線」を提案
- **文体分析** — サンプル本文（最大約6000字）から文長・文字種比率・語彙特性など約24項目をAIが評価し、再現用の「文体指示文」をプリセット/カードに保存。jReadabilityによる本家の読みやすさスコアも計測（MeCab+UniDic同梱版は実計測、未導入環境は近似値）
- **カード＆タグ呼び出し** — `#タグ` で会話中にいつでも注入（`##タグ` は今回のみ）
- **プロンプト最適化** — 入力中の指示文をAIが推敲してから送信

### 記憶とコスト管理
- **ハイブリッド記憶** — 直近1往復は生テキストで完全記憶、過去9往復は英語に圧縮して保持。口調を保ちつつトークンを節約
- **コンテキスト自動圧縮** — 予算超過時に古いやり取りを要約。使用量はトークンバッジで可視化
- **繰り返しワード自動検出** — 本文中の過剰な繰り返しを検出し、言い換え指示をプロンプトに自動注入

### 資料・プロジェクト管理
- **ソース（NotebookLM的Q&A）** — 資料をプロジェクトごとに登録し、AIが【出典: ソース名】付きで回答
- **会話プロジェクト** — 複数の会話を作品単位でグループ化・フィルタ
- **ノート（Zettelkasten）** — `[[名前]]`リンク・`#タグ`・被リンク一覧。カード/ソースへの昇格も可能
- **物語グラフ** — カード・ドキュメント・原稿シーン・会話の関連を可視化
- **クイックマクロ** — 任意のキー割り当てで指示・ツールを即実行（アプリ内／グローバルホットキー対応）
- **ブラウザ風タブ** — 複数の会話をタブで並行管理。下書きは会話ごとに自動保存

### 品質管理・バックアップ
- **一貫性チェック** — カードの数値（歳・身長・距離など）と本文の矛盾・未登場・重複を検出
- **横断検索・置換** — 原稿/ドキュメント/ソースを対象にした検索と一括置換
- **シーン履歴** — 原稿シーンの変更前テキストを自動保存（20版/シーン）
- **タイムマシン** — 全データの定期スナップショット。任意時点へ復元可能
- **バックアップ / 復元** — 全データのJSONエクスポート・インポート
- **カード知識DB** — カードに別名・関連を登録し、登場シーンの逆引きやAI応答からのカード候補抽出に対応

### 対応環境
- **デスクトップ** — Windowsインストーラー / ポータブルexe（Electron）
- **ブラウザ・スマホ・ChromeOS** — 同一LAN内アクセスやセルフホストでURLを開くだけ
- **テーマ** — ライトモード固定

## インストール

[Releases](https://github.com/WLeln/ai-novelist-studio/releases) から最新の `AI Novelist Studio Setup x.x.x.exe`（インストーラー）またはポータブル版をダウンロードしてください。

## 起動方法（開発者向け）

```sh
npm install
npm start          # → http://localhost:3737
npm run desktop    # Electronアプリとして起動
npm run dist       # Windowsインストーラーをビルド
```

### 文体分析の本家スコア（MeCab + UniDic）

ツールメニューの「文体を分析」は、MeCab + UniDic があれば **jReadability の本家スコアを実計測**します。リリース版インストーラーには `tools/`（約200MB）が同梱されるため追加設定は不要です。開発環境やセルフホストで有効化する場合：

```sh
npm run setup:readability   # MeCab + UniDic を tools/ に自動ダウンロード
```

あるいは環境変数で独自の辞書を指定できます：

- `JREAD_UNIDIC` — UniDic辞書ディレクトリ（`sys.dic` を含むもの）
- `PATH` — `mecab` コマンドが見つかるようにする

MeCab/UniDicが無い環境では自動的に近似メトリクスにフォールバックします。

クラウド（スマホ・ChromeOS）で使う場合は [DEPLOY.md](DEPLOY.md) を参照してください。

## 設定

初回起動後、設定画面でAPIキーを登録してください：

- **接続先・モデル** — AIのべりすと固定（`spiko_ultra`）
- **APIキー** — のべりすとのAPIキー

## 技術構成

- **サーバー**: Node.js + Express（REST API + AI APIプロキシ + 静的配信）
- **データ**: SQLite（`node:sqlite`、初回起動時に旧JSONから自動移行）
- **フロントエンド**: HTML/CSS/バニラJS ES Modules（TipTapエディタ + marked + DOMPurify）
- **デスクトップ**: Electron（contextIsolation有効）
- **CI/CD**: GitHub Actions でタグpush→Windowsビルド→Releases自動公開

## セキュリティ

- APIキーはサーバー側にのみ保存され、ブラウザには送信されません
- Markdown出力はDOMPurifyでサニタイズ
- `ACCESS_TOKEN` 設定時はログイン画面＋Cookie認証（`?key=` URL方式は廃止）
- Hostヘッダ検証・CSRF対策・プロトタイプ汚染対策・ログインレート制限を実装
- LAN公開は `lanAccess` 設定で明示的に有効化（同一Wi-Fi内のみ・`ACCESS_TOKEN`必須）
- クラウド公開時はHTTPS必須（DEPLOY.md参照）

## About

AI Novelist Studio は、AIのべりすととの対話を通じて小説を「会話 → 整理 → 原稿化 → 管理」する流れを一つのツールにまとめた個人開発プロジェクトです。

## クレジット

- フロントエンドのMarkdown描画に [marked.js](https://marked.js.org/) / [DOMPurify](https://github.com/cure53/DOMPurify) を使用
- リッチテキストエディタに [TipTap](https://tiptap.dev/) を使用
- 文体分析に [jreadability](https://github.com/joshdavham/jreadability)（MeCab + UniDic）を使用。MeCabはトライデュアルライセンス（BSD選択）、UniDicはNINJALのライセンスに基づき同梱
- AI推論はユーザー自身のAPIキーで実行（本ソフトウェア自体はAIモデルを内蔵しません）
- 接続先はAIのべりすと（`spiko_ultra`）に固定されています
